    How the detector works

    1. You enter a URL. It is never opened or visited — only the text is analysed.
    2. 12 features are extracted, such as length, dots, hyphens, IP addresses, HTTPS, subdomains and risky words.
    3. A Random Forest model votes. 200 decision trees each judge the features; the share voting "phishing" becomes the confidence score.
    4. You see the verdict with a risk level and the features that raised the warning.

    Learn about phishing

    What is phishing?

    Phishing is a scam where someone pretends to be a trusted company or person to trick you into sharing passwords, bank details or other private information.

    How phishing websites work

    The attacker builds a fake page that looks like a real login or payment page, then sends the link by email, SMS or social media. Anything you type goes straight to the attacker.

    Common signs

    • A web address that is odd, long or uses an IP number
    • Brand names inside a different domain (paypal.com.example.xyz)
    • Urgent messages such as "verify now or lose access"
    • Missing HTTPS or an @ symbol in the link
    • Shortened links that hide the destination

    How machine learning helps

    A model learns from thousands of labelled links which URL patterns are usually phishing. It can then score new links instantly, including ones no human has reported yet. It can still be wrong, so it is a helper, not a guarantee.

    How to protect yourself

    • Type important addresses yourself or use bookmarks
    • Never click links in unexpected messages
    • Use a password manager — it will not fill in fake sites
    • Turn on two-factor authentication
    • Keep your browser and devices updated
